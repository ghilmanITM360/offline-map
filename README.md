# Karachi Ijtema Offline Navigation

A true offline-first Android app for Karachi Ijtema navigation.

## Features
- Download map once, use fully offline
- Current location tracking
- Search blocks or landmarks
- Shortest route calculation (Dijkstra/A*)
- Walking-only routes on rastas
- Block entry only from allowed gate corners

## Getting Started

### Install
```bash
npm install
```

### Start Expo
```bash
npx expo start
```

### Run on Android device
- Install Expo Go on Android
- Scan the QR code

### Optional Android build
```bash
npx expo run:android
```

- Simulated source places the walker on GATE_01's node; destination GATE_01 -> `destination.nodeIds.includes(near.id)` is correctly true (`NavigationController.ts:649`). Destination Gate 03 routed because it is a different node.
- Data check (venueAdapter + real graph): GATE_01/03/08 each map to a single node of the same id at exactly the gates.json coordinates; nearest nodes to the Gate 08 fix and its offsets are GATE_08/SPNP-01/B3_C1 (never GATE_01). No node-ID aliasing, no venue mismatch. Classification: **consumer/harness (default simulated location source)**; no SDK defect, no data issue. No source change made.
- Earlier "live route built from the injected fix" claims in this file were the simulated fix, not the injected one.

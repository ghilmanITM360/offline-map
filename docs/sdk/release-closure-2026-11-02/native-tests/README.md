# Native Arrival touch fixture

The two files here are the exact nativeXCTest harness that passed on source70275f3's PC2 Release simulator app. Precondition: installed com.example.sdkconsumer already at Arrival, simulator content-size accessibility-extra-extra-extra-large. No launch/reset in the test; it activates the existing app. Test uses native swipeUp and coordinate taps, not accessibility activation. Current assertions prove isHittable and exit; full-frame/safe-area assertions and normal/XL/Urdu variants remain pending.

Copy both files into a fresh external build directory (not another Git checkout). Run the task-local isolated Ruby wrapper with create_project.rb. Then `xcodebuild -project <external>/TouchAcceptance.xcodeproj -scheme TouchAcceptance -destination id=B4FE838C-215C-4C4C-9D64-B2952783A5D6 -parallel-testing-enabled NO -derivedDataPath <external>/DerivedData -resultBundlePath <fresh-external>.xcresult CODE_SIGNING_ALLOWED=NO -jobs 2 test`. Use a fresh result path. The executed first command omitted parallel-testing flag, but xcresult confirms it used that existing device, not a clone. Inspect `xcresulttool get test-results summary` and export attachments. Do not infer all size/language/safe-area variants from one passing test.

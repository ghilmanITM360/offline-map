# Complete Component Inventory

Every reusable component under `src/views/components/` (branch
`docs/ui-ux-audit-reconciliation`, as of commit `1995fa7`), read in full and
recorded here. This is a source-level inventory — "Tests" and "Accessibility"
columns reflect what the code actually does, not runtime-confirmed behavior
unless cross-referenced to a runtime-verified issue below. Screens rendering
each component were found via `grep` for the component name across `src/`.

Issue cross-references were inferred from source patterns, not by re-reading
every named issue's body — spot-checked #144, #151, #156 against their actual
bodies while writing this up (see notes inline); the rest should be treated as
a starting point for reconciliation, not a final claim.
